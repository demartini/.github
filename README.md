# .github

Default community health files and contribution templates shared across my open source projects.

This repository provides the common documentation and GitHub templates used to keep contribution workflows consistent across projects.

These files are intended for contributors, maintainers, and anyone opening an issue or pull request.

## What's included

- Code of Conduct
- Contributing Guidelines
- Security Policy
- Issue templates
- Pull Request template
- GitHub Sponsors configuration

Project-specific configuration and documentation should remain in the repository where it applies.
